# 当日チェックリスト

印刷して会場に持ち込む用。詳しい手順は `docs/operations.md`。

## A. 前日まで（管理者）

- [ ] 本番用ライブを作成（**限定公開** / **埋め込み許可 ON** / **チャット無効**）
- [ ] **予備用ライブ**をもう 1 本作成し、URL を管理画面の「予備の配信 URL」に入れて保存
- [ ] 両方とも **自動終了（auto-stop）を OFF**
- [ ] **再利用可能なストリームキー**を設定
- [ ] 遅延は **「通常の遅延」**（低遅延を選ばない）
- [ ] ビットレートは **720p30 / 2500kbps 程度**
- [ ] プログラムを入力して保存（**選手名は入れない**。種目名まで）
- [ ] 配信状態を「配信前にする」、開始予定の文言を入れて保存
- [ ] `node tools/check-rules.js` を実行し **7/7 OK** を確認
- [ ] **当日操作するスタッフ全員の端末で管理画面にログイン**（当日は入力不要になる）
- [ ] 中継ページの QR コードを印刷（会場入口・プログラム冊子・案内メール）
- [ ] スマホで中継ページを開き、表示されることを確認

## B. 当日 開始前（30 分前）

- [ ] カメラ・三脚・**給電**を設置（スマホ配信なら発熱対策も）
- [ ] 回線を確認（可能なら有線 / モバイルなら電波を確認）
- [ ] YouTube 側で配信開始
- [ ] 管理画面に配信 URL を貼る → **欄の下に「OK（動画 ID: …）」が出ることを確認**
- [ ] **プレビューに映像が出ることを目で確認**（真っ黒なら「埋め込み許可」が OFF）
- [ ] **「保存」を押す**（URL は保存しないと反映されない）
- [ ] 「配信中にする」を押す（こちらは保存不要）
- [ ] **別の端末**で中継ページを開き、映っていることを確認
- [ ] 音が出ることを確認

## C. 配信中

- [ ] 種目が変わったら **「次の種目へ進む」**を押す（保存不要）
- [ ] 状況が変わったらテロップを書き換えて **「保存」**
- [ ] ときどき別端末で中継ページを見て、映像が生きているか確認

## D. 配信が切れたとき（あわてない）

```
① まず「中断中にする」を押す        ← 保存不要。最初にこれ
     視聴者に「復旧作業中です」と出る

② 機材を繋ぎ直す
     戻った  → 「配信中にする」を押す。終わり
     戻らない → ③へ

③ 「予備 URL に切り替える」→「配信中にする」
     どちらも保存不要。視聴者の画面は自動で切り替わる

④ 予備も駄目なら
     YouTube で新しいライブを作る
     → URL を貼る →「保存」→「配信中にする」
```

**「全員の画面を再読み込み」は最終手段。** まず 30 秒待つ。
複数の人から「切り替わらない」と言われたときだけ押す（全画面が解除される）。

## E. 終了後

- [ ] 「終了にする」を押す
- [ ] アーカイブを見せる場合は、アーカイブ URL を入れて **「保存」**
- [ ] YouTube 側の公開設定を確認
- [ ] 端末を人に渡す場合はログアウト

## 困ったとき

| 症状 | まず疑うこと |
|---|---|
| 映像が真っ黒 | YouTube の「埋め込みを許可」が OFF |
| 「動画は再生できません」 | 配信が非公開 / 削除されている |
| 一部の人だけ見られない | その人のネットワークが YouTube を遮断（**対処不能**） |
| 実際の試合と違うと言われる | 正常（配信は数十秒遅れる） |
| 文字を変えたのに反映されない | 「保存」を押していない（画面下の赤い「未保存」を確認） |
| 「次の種目へ進む」が押せない | プログラムに未保存の変更がある。先に「保存」 |
| 管理画面にログインできない | パスワード誤り。**当日その場での再発行はできない** |

## 絶対にやらないこと

- テロップ・プログラムに **選手名・所属・連絡先を書かない**（誰でも見られます）
- 大会当日に「選んだイベントを配信中にする」を押さない
- 大会当日にコートを削除しない
